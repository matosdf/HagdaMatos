# [P0][10] Validar ponta a ponta e preparar lançamento controlado

## Objetivo

Validar ponta a ponta e preparar lançamento controlado.

## Dependências

Etapa 03, Etapa 04, Etapa 05, Etapa 07, Etapa 08

## Passo a passo

- [ ] Executar npm test, npm run typecheck e npm run build; guardar evidências sanitizadas.
- [ ] Validar os fluxos reais do Sandbox com visitante, cliente pendente, cliente paga, cancelada com saldo, vencida e proprietária.
- [ ] Conferir preço, total N, limite de períodos, documentos e datas em desktop/celular.
- [ ] Verificar ausência de segredos em bundle, Git, logs e issues; conferir conteúdo privado e políticas RLS/storage.
- [ ] Preparar Vercel preview, domínio www.hagda.com.br, variáveis por ambiente e plano de recuperação de falhas.
- [ ] Validar monitoramento de webhook e procedimentos manuais antes de habilitar rotinas financeiras e de retenção.
- [ ] Solicitar autorização específica para push/deploy e, separadamente, para produção financeira; este backlog não autoriza publicação ou cobrança real.
- [ ] Executar lançamento acompanhado e documentar retorno/rollback sem apagar o histórico financeiro.

## Critério de conclusão

Aceite de lançamento registrado, domínio e ambiente conferidos, sem ativação automática de produção.

## Limites

Não incluir credenciais ou dados pessoais nas issues. Não executar cobrança real, migração externa, push ou deploy sem a autorização específica aplicável.
