# [P1][05] Organizar e homologar a biblioteca comum de vídeos

## Objetivo

Organizar e homologar a biblioteca comum de vídeos.

## Dependências

Etapa 02

## Passo a passo

- [ ] Aguardar produção dos vídeos; reunir título, descrição e ordem das aulas.
- [ ] Escolher armazenamento privado de acordo com tamanho, volume e custo; confirmar necessidade de streaming para arquivos longos.
- [ ] Testar com um arquivo sintético pequeno e sem dados de cliente; nenhum vídeo pago pode ficar em public/.
- [ ] Usar /admin para upload privado até 50 MB ou painel de armazenamento para arquivos maiores compatíveis com o plano.
- [ ] Cadastrar primeiro como rascunho; revisar e publicar para a biblioteca comum.
- [ ] Testar edição, despublicação e reprodução com cliente válida, vencida e bloqueada.
- [ ] Validar expiração dos links, busca dentro do vídeo, acesso no celular e comportamento em conexão instável.

## Critério de conclusão

Biblioteca comum organizada e vídeos acessíveis somente após autorização; nenhum arquivo real exposto publicamente.

## Limites

Não incluir credenciais ou dados pessoais nas issues. Não executar cobrança real, migração externa, push ou deploy sem a autorização específica aplicável.
