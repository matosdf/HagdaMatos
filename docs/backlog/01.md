# [P0][01] Preparar Supabase de testes e separar as credenciais

## Objetivo

Preparar Supabase de testes e separar as credenciais.

## Dependências

Pode ser planejada independentemente.

## Passo a passo

- [ ] Criar um projeto Supabase de testes separado da produção, sem dados reais.
- [ ] Seguir docs/supabase-passo-a-passo.md até a etapa de configuração pública.
- [ ] Localizar URL e chave publishable; nunca colar secret/service_role, senhas ou tokens nesta issue.
- [ ] Escolher isolamento: servidor iniciado pelo usuário em terminal separado ou ambiente/usuário isolado. Variáveis Windows não garantem segredo perante processos do mesmo usuário.
- [ ] Executar scripts/Start-HMLocal.ps1 pessoalmente, mantendo cobrança e Asaas desativados.
- [ ] Compartilhar apenas o resultado funcional ou o relatório de presença/ausência de variáveis.

## Critério de conclusão

Projeto de testes identificado, servidor local aberto e nenhuma chave em conversa, print, issue ou commit.

## Limites

Não incluir credenciais ou dados pessoais nas issues. Não executar cobrança real, migração externa, push ou deploy sem a autorização específica aplicável.
